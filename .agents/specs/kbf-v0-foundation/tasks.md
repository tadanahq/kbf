- [x] `extends` resolution goes recursive, cycle-detected — `Universe.Chain(pkg)` (`internal/lint/universe.go`) replaces the old single-hop `ExtendsRoot`: walks the full chain, nearest ancestor first, stops (not hangs) on a missing link or a repeated package name. A cycle is `KBF011` on every package that's part of it (each detects the same loop independently starting from itself). A missing ancestor anywhere up the chain degrades exactly like today's missing-immediate-parent case: whatever chain resolved before the gap is still used as context.
